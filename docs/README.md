# Wrapped in Love website concept

A responsive, multi-page website concept for Wrapped in Love Doula & Lactation Support. The site is buildless HTML, CSS, and JavaScript and can be published directly through GitHub Pages.

## Publish with GitHub Pages

1. Add all files in this folder to a GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**, select the branch and `/(root)`, then save.
3. The site opens at `index.html`; all navigation uses relative links and works from a GitHub Pages project URL.

## Pages and interactions

- Home, Care, Our Story, Community, Classes, Booking, Client Portal, and Shop
- Booking request flow with sample dates and topic selection
- Class registration with sample prices and a simulated checkout confirmation
- Client portal demo with appointment, resource, message, and payment tabs
- Concept shop with browser-local cart and simulated checkout
- Responsive navigation, scroll reveal, gentle motion, and reduced-motion support

All appointment availability, events, clients, payments, products, prices, and confirmations are illustrative. Form submissions do not leave the browser; no booking, registration, payment, order, or message is sent. Do not enter real sensitive information into the portal demo. A live site would need secure scheduling, client records, consent/intake forms, payment processing, and appropriate privacy controls.
